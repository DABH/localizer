Thanks for installing the Localizer GitHub App.

- **If the account that owns the repository has a [subscription](/pricing/)** (or an allowlist entry),
  the first pull request arrives within minutes. It sets up the configuration, the catalogs and the
  one-line integration; merge it, and the translations stay in sync from then on.
- **If it doesn't, nothing happens yet.** Localizer only works for subscribed accounts. [Subscribe](/pricing/)
  for that account (a personal account takes Solo, Team or Enterprise; an organization Team or Enterprise),
  then push a commit or reinstall the App on the repository to start.

Questions or trouble? Email [saluton@locale.dev](mailto:saluton@locale.dev).
