Your subscription is active as soon as Polar confirms the payment, usually within a minute. Polar has
emailed you a receipt and a link to its customer portal, where you can manage the subscription.

<Steps>

1. **Connect a repository** of the account you subscribed for, with the GitHub Action or the GitHub App.

2. **Merge the onboarding pull request.** It adds the configuration, one catalog per language and the
   one-line integration.

3. **Keep shipping.** When your strings change, the translations pull request updates itself.

</Steps>
